# Работы по курсу "Дизайн-системы"

В этом репозитории находятся домашние задания по курсу и рабочие коммиты с пар.

Актуальное:
- Vanilla-extract: theme.css.ts & [component].css.ts, ThemeProvider.tsx
- Button component (a/href + icon start/end)
- Calendar component
- DatePicker component

Legacy: 
- ThemeProviderOld.tsx
- css modules
- variables.css

Посмотреть примеры компонентов: 

```bash
npm run dev
```

Компоненты помещаются сразу в App.tsx. Там же можно настроить и тему для компонентов.

Собрано с помощью Vite.
